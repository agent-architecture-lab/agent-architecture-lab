## recruit-001 | 신청 기간과 선발 결과 안내
신청 기간은 2026년 9월 1일(화)부터 9월 17일(목)까지입니다.
신청은 모집 공고의 스터디 신청 바로가기 링크에서 합니다.
선발 결과는 9월 30일(수)에 개별 안내합니다.

## recruit-002 | 스터디 리더
스터디 리더는 데이터 엔지니어링 실무자이며 오픈소스 사용자 모임 운영진으로 활동하고 있습니다.
리더의 실명과 소속은 이 데모 자료에서 익명화했습니다.

## recruit-003 | 스터디 주제와 진행 형태
스터디 주제는 에이전트 아키텍처 랩입니다.
OpenAI Codex 기반 AI 코딩 에이전트를 활용해 신청서 스크리닝·매칭, FAQ 응답, 주간 회고 피드백까지 자동화하는 커뮤니티 운영 에이전트를 처음부터 함께 설계하고 구현합니다.
여러 커뮤니티 운영에서 리더가 신청자 설문을 수작업으로 스크리닝·매칭하는 현실에 착안한 주제입니다.
오픈소스 레포 all-agentic-architectures(35개 프로덕션급 에이전트 아키텍처 라이브러리)를 교재로 삼습니다.
이론 학습과 실제 구현을 병행하는 8주 프로젝트형 스터디입니다.

## recruit-004 | 목표 1: 개인 역량
8주 안에 에이전트 아키텍처 3종(Reflection, RAG, Multi-Agent)을 직접 구현합니다.
"LLM은 범주형 판단만, 최종 결정은 코드가 한다"는 deterministic-picker 원칙을 매주 실습합니다.
감이 아닌 구조와 수치로 에이전트를 설계하는 습관을 체화하는 것이 목표입니다.

## recruit-005 | 목표 2: 완주와 증거
완주율 100%를 목표로 합니다.
완주 기준은 전원 8회 중 6회 이상 출석하고 담당 트랙을 1개 이상 배포하는 것입니다.
전원이 자기 이름의 GitHub 레포, PR 리뷰 경험, 발표 경험을 포트폴리오로 가져갑니다.
모든 과제와 진행 상황은 GitHub Issues와 Projects 보드로 투명하게 트래킹합니다.

## recruit-006 | 목표 3: 커뮤니티 환원
완성된 에이전트는 익명화 샘플 신청서로 End-to-End 성공률 80% 이상을 검증합니다.
검증 후 잇츠 스터디와 우먼잇츠 운영진에 차기 기수 운영 도구로 제안합니다.

## recruit-007 | 프로젝트 결과물 계획
GitHub 공개 코드: 스크리닝·매칭, FAQ Q&A, 회고 피드백, 오케스트레이터 4개 모듈의 오픈소스 레포이며 노트북, 실행 결과, 벤치마크 리포트를 포함합니다.
발표 자료: 8주 여정과 아키텍처별 설계 판단 근거를 정리한 슬라이드를 만듭니다.
시연 데모: 익명화한 신청서를 입력하면 스크리닝, 매칭, FAQ 응답, 회고 피드백까지 자동 실행되는 라이브 데모를 만듭니다.
정량 지표: 팀 누적 아키텍처 구현 18개(6명×3개), GitHub 커밋 150개 이상, 모듈별 벤치마크 리포트(정확도·응답시간·비용 중 1개 이상 실측)를 목표로 합니다.

## recruit-008 | 모집 대상
OpenAI API와 Codex로 실전 프로젝트를 직접 만들어 보고 싶은 개발자와 취업준비생을 모집합니다.
백엔드, 데이터, PM 등 배경은 무관합니다.

## recruit-009 | 필요 기술 스택과 권장 사전지식
Python 기초 문법(함수, 클래스, 비동기 호출 정도)이 필요합니다.
REST API 호출 경험(requests, fetch 등으로 외부 API를 불러본 경험)이 필요합니다.
Git 기본 사용법(clone, commit, push, PR)이 필요합니다.

## recruit-010 | 함께하고 싶은 분
코딩 에이전트를 질문만 하는 도구가 아니라 함께 설계하는 협업자로 다뤄 보고 싶은 분과 함께하고 싶습니다.
8주 완주 의지가 있는 분을 찾습니다. 트랙이 서로 이어지는 구조라 중도 이탈이 팀 전체에 영향을 줍니다.
왜 이렇게 설계했는지 스스로 설명하고, 매주 코드 리뷰에서 피드백을 주고받는 데 열려 있는 분을 찾습니다.

## recruit-011 | 모집 정원
모집 정원은 리더 포함 6명입니다.

## recruit-012 | 진행 방식과 장소
진행 방식은 온라인과 오프라인 혼합입니다.
정규 세션은 100% 온라인으로 진행하며 디스코드로 초대할 예정입니다.
킥오프 또는 마지막 세션 전후로 희망하면 강남역 인근에서 오프라인 모임을 가질 수 있으며, 오프라인 모임은 선택이고 전원 참석이 필수가 아닙니다.
재단 주최 공식 성과공유회(12월 16일)는 재단 공지에 따라 별도로 참석합니다.

## recruit-013 | 사전 준비물과 개발 환경
필수 계정은 OpenAI 계정과 GitHub 계정입니다.
개발 환경으로 Node.js(Codex CLI 설치용), Git, 터미널 사용 가능 환경(Windows는 WSL2 권장), 코드 에디터(VS Code 등)가 필요합니다.
사전 학습 권장 자료는 all-agentic-architectures 레포, OpenAI Codex 공식 문서의 AGENTS.md 개념, Python 기초 문법입니다.
Python 기초가 필요한 인원을 대상으로 부트업 세션을 제공할 수 있습니다.

## recruit-014 | 전체 일정과 정규 모임 시간
잇츠 스터디 오리엔테이션은 10월 2일(금) 온라인으로 진행합니다.
팀 오리엔테이션은 10월 3일(토) 오프라인으로 강남역 또는 성수역 근처에서 진행합니다.
활동 기간은 10월 3일(토)부터 11월 30일(월)까지입니다.
정규 모임은 매주 목요일 19:30~21:30에 총 8회 진행합니다.
성과공유회는 12월 16일(수)입니다.

## recruit-015 | 주차별 계획: OT~4주차
OT(10월 3일 토): 팀 오리엔테이션으로 자기소개, 역할 정렬, 개발환경 세팅을 점검합니다.
1주차(10월 8일 목): 스크리닝·매칭 에이전트 이론(Reflection 패턴)을 배우고 구현을 시작합니다.
2주차(10월 15일 목): 스크리닝·매칭 에이전트 구현을 완료하고 코드 리뷰와 데모를 진행합니다.
3주차(10월 22일 목): FAQ 에이전트 이론(RAG 패턴)을 배우고 구현을 시작합니다.
4주차(10월 29일 목): FAQ 에이전트 구현을 완료하고 코드 리뷰와 데모를 진행합니다.

## recruit-016 | 주차별 계획: 5주차~성과공유회
5주차(11월 5일 목): 회고 피드백 에이전트 이론(Multi-Agent 패턴)을 배우고 구현을 시작합니다.
6주차(11월 12일 목): 회고 피드백 에이전트 구현을 완료하고 코드 리뷰와 데모를 진행합니다.
7주차(11월 19일 목): 오케스트레이터 통합을 설계하고 3개 모듈 연결을 시작합니다.
8주차(11월 26일 목): 오케스트레이터 통합을 완료하고 최종 데모와 발표 리허설을 진행합니다.
성과공유회(12월 16일 수): 재단과 OpenAI가 공동 주최하는 프로젝트 발표회입니다.
